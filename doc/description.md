# idea-brief-clock

## 任务

制作一个安卓时钟 app brief clock 的 MVP。它和常规闹钟相比，主要带有特色功能 `brief alarm`， `nap roulette`。并确保代码优质（例如正确，可读性强，简洁，模块化，健壮，可测试，可维护，可拓展，性能合理，安全，工程化良好）。

## 做法

在 github 上`寻找成熟完善的基础安卓时钟`项目并`进行改造`（必须star数>=1k，如果没有，则提醒我人工审核）。并且注意`包括但不限于``许可证`等问题。

## 特色功能

1. `brief alarm`
    常规闹钟功能
    按住录音并设为闹钟铃声
2. `nap roulette`
    2.5d左轮手枪，有动画
    设定睡多少时间，然后开赌，在时间内停止睡眠视为失败
    开枪音效
    扳机音效
3. 统计
    nap roulette的统计信息，有美观直观的图表。

> 在底部导航栏中切换这3个页面
