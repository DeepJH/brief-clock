# Brief Clock (讲解时) v0.1.2 改进实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现小憩时长按 1 分钟精度步进微调、添加关于与“无政治声明”弹窗、支持赞助入口架构、优化双语体验并解决历史细节遗留。

**Architecture:** 
- 将 `defaultNapOptions` 重构为以 1 分钟为基准的动态序列（10s 测试 + 1m..120m），并在选时器区域提供 `+1m` / `-1m` 快速微调触控控件；
- 在设置页面中增加“关于与声明”模块，展示应用中文同音梗的“无政治立场免责声明”；
- 增加轻量“赞助支持”展示模块架构（弹窗二维码/爱发电/GitHub Sponsors 链接跳转）。

**Tech Stack:** Kotlin 2.0.20, Jetpack Compose, Material 3, Android SDK 26-35.

- [ ] **Step 3: Implement 1-minute increment generator & picker stepper**

In `VerticalDurationWheelPicker.kt`:
```kotlin
fun generateNapOptions(isChinese: Boolean = false): List<NapDurationOption> {
    val list = mutableListOf<NapDurationOption>()
    list.add(NapDurationOption(10, if (isChinese) "10秒 (测试)" else "10s (Test)"))
    for (m in 1..120) {
        list.add(NapDurationOption(m * 60, if (isChinese) "${m}分钟" else "${m} mins"))
    }
    return list
}
```
